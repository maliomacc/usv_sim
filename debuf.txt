2D LiDAR + ZED — Topic Kontrol Komutları:
  ros2 topic hz /scan                            # ham LiDAR (5.5 Hz)
  ros2 topic hz /scan/filtered                   # filtreli LiDAR
  ros2 topic hz /roboboat/sensors/camera/image   # ZED RGB (30 Hz)
  ros2 topic hz /zed/depth                       # ZED derinlik
  ros2 topic echo /fusion/target                 # SensorFusion çıktısı
  ros2 topic echo /gate_center                   # HSV kapı tespiti
  ros2 topic echo /kamikaze_target               # HSV duba tespiti
  ros2 topic echo /odometry/filtered             # EKF konum tahmini
  ros2 topic echo /mission_state                 # görev aşaması
